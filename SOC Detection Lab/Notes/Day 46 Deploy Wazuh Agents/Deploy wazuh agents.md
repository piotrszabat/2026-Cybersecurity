# Day 46 — Wazuh Agent Deployment

## Objective

The objective of Day 46 was to deploy **Wazuh agents** to the Windows endpoints in the lab environment and confirm successful communication with the **Wazuh server (WAZ01)**.

This step extends the monitoring capabilities of the SOC environment by enabling endpoint telemetry collection from multiple hosts.

---

# Environment Overview

The lab environment currently consists of two network segments.

```
NET-CORP
├─ DC01
├─ PC01
└─ SRV01

NET-SOC
├─ WAZ01
└─ SPLK01
```

Telemetry flow implemented in this phase:

```
Windows endpoints → Wazuh Agents → WAZ01 → Wazuh Dashboard
```

---

# Step 1 — Verify Wazuh platform health

Before deploying agents, the Wazuh services on **WAZ01** were verified to ensure the platform was operational.

Commands executed:

```bash
sudo systemctl status wazuh-manager
sudo systemctl status wazuh-dashboard
sudo systemctl status wazuh-indexer
sudo systemctl status filebeat
```

All services were confirmed to be **running**, indicating that the Wazuh stack was functioning properly.

---

# Step 2 — Verify dashboard access

The Wazuh dashboard was accessed using a browser.

Example:

```
https://192.168.50.20
```

Successful login confirmed that the management interface was operational and ready for agent deployment.

---

# Step 3 — Confirm network connectivity

Because the endpoints are located in **NET-CORP** and the Wazuh server is in **NET-SOC**, traffic must pass through **FW01 (pfSense)**.

The following ports were allowed from **NET-CORP → WAZ01**:

```
TCP 1514
TCP 1515
TCP 55000
```

These ports are required for Wazuh agent communication and enrollment.

---

# Step 4 — Generate agent installation commands

The Wazuh dashboard deployment wizard was used to generate installation instructions.

Navigation path:

```
Agents management → Summary → Deploy new agent
```

Deployment parameters:

```
Operating system: Windows
Server address: 192.168.50.20
Agent names:
DC01
PC01
SRV01
```

---

# Step 5 — Install Wazuh agent on DC01

The agent was installed on **DC01** using PowerShell with administrative privileges.

Example command:

```powershell
Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.14.3-1.msi -OutFile "$env:TEMP\wazuh-agent.msi"

msiexec.exe /i "$env:TEMP\wazuh-agent.msi" /q WAZUH_MANAGER="192.168.50.20" WAZUH_AGENT_NAME="DC01"
```

After installation, the service was started:

```powershell
Start-Service wazuhsvc
Get-Service wazuhsvc
```

The service status was verified as **Running**.

---

# Step 6 — Install Wazuh agent on PC01

The same installation procedure was executed on **PC01**.

```powershell
msiexec.exe /i "$env:TEMP\wazuh-agent.msi" /q WAZUH_MANAGER="192.168.50.20" WAZUH_AGENT_NAME="PC01"

Start-Service wazuhsvc
Get-Service wazuhsvc
```

The agent successfully connected to the Wazuh manager.

---

# Step 7 — Install Wazuh agent on SRV01

The Wazuh agent was installed on **SRV01** using the same deployment method.

```powershell
msiexec.exe /i "$env:TEMP\wazuh-agent.msi" /q WAZUH_MANAGER="192.168.50.20" WAZUH_AGENT_NAME="SRV01"

Start-Service wazuhsvc
Get-Service wazuhsvc
```

All three systems were successfully configured as Wazuh agents.
